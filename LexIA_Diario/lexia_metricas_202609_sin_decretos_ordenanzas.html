BiPay		El clasificador local no tiene una regla para autorizaciones SBS de empresas emisoras de dinero electronico.Agregar regla: empresa emisora de dinero electronico y autorizan funcionamiento => SI / INFORMATIVA.

Financiamiento MIPYME		No existe un criterio para reglamentos que promueven financiamiento MIPYME, emprendimientos y startups.Agregar regla: financiamiento MIPYME, emprendimientos, startups o DU 013-2020 => SI / INFORMATIVA.

Llamadas y mensajes comerciales		No existe un criterio para regulacion de llamadas y mensajes de texto con fines comerciales o publicitarios.Agregar regla: numeracion, llamadas, mensajes de texto y fines comerciales/publicitarios => SI / IMPACTO BAJO.
