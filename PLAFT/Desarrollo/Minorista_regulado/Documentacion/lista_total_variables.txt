  -> DESCARTADA por alta correlacion (Pearson y/o Spearman, umbral >=0.9) con otra

CORR-02
  -> DESCARTADA en 02.bivariados+EDA_train+seleccion_variables.ipynb por alta
     correlacion (>0.70) con otra variable que si quedo en el modelo final.

UNICO
  -> DESCARTADA por ser una variable constante (un solo valor / varianza cero) en
     la base analizada. Hallazgo documentado en 0.limpieza_datos.ipynb.

ID

     particion de la tabla (ej. documento, codigo unico, periodo). Se excluye
     explicitamente del set de variables candidatas en los notebooks revisados.

TARGET
  -> NO ES FEATURE: variable utilizada para construir la variable objetivo (target)
     del modelo, no se evalua como predictor.
