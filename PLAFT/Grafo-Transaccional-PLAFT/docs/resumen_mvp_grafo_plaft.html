Interbank · PLAFT · Resumen de Speckit
interbank

Grafo transaccional para investigación PLAFT

El proyecto construye una representación integrada de clientes, cuentas, transferencias y señales PLAFT para investigar relaciones financieras y patrones de movimiento de dinero.

PROBLEMA

Información dispersa

La investigación depende hoy de consultas manuales en varios sistemas sin una vista estructural de la red.

SOLUCIÓN

Grafo transaccional

Conecta entidades y hechos financieros, manteniendo el vínculo con cada registro fuente.

RESULTADO

Investigación trazable

Un analista puede entender el contexto, documentar evidencia y sustentar el caso investigado.

01 · Alcance del MVP

Empezar focalizados y con trazabilidad

El MVP no construye el grafo de toda la cartera. Parte de los clientes sospechosos y sus contrapartes directas; la profundidad inicial es un salto y luego podrá ampliarse.

Qué datos incorpora

Clientes, cuentas, productos y transferencias; además, alertas PLAFT, ROS, condición PEP, casos investigados y catálogo documental.

Cómo se identifica al cliente objetivo

Alerta, ROS, PEP vigente, caso asociado, lista objetivo PLAFT o una regla configurable y documentada.

02 · Para empezar a armar los grafos

Necesitamos datos listos, reglas claras y una primera versión controlada

1. Mapeo de datosConfirmar fuentes, dueño, campos, llaves y periodicidad de clientes, cuentas, titularidades, transferencias y señales.
→
2. Reglas de negocioDefinir criterios de sospecha, fecha de corte, profundidad inicial y tratamiento de anuladas/revertidas.
→
3. Calidad y seguridadValidar esquema, duplicados e integridad; usar datos sintéticos o anonimizados y permisos aprobados.
→
4. Primer subgrafoConstruir y validar un caso piloto: cliente, cuentas, contrapartes y transferencias con trazabilidad.

Entregable inicial

Tablas de nodos y aristas versionadas, con cada transferencia preservada como hecho individual y una capa agregada para análisis.

Siguiente decisión práctica

Completar el mapeo físico-conceptual con las áreas dueñas de datos y seleccionar el primer conjunto de clientes objetivo para el piloto.
